📌 使用方法

1. NFC编辑器给每张215贴纸写入工具名称（NDEF Text格式）
2. 点「记录」→ 逐一贴触 → 点「结束」
3. 点「清点」→ 逐一贴触 → 匹配项实时从两侧消失
4. 点「结束」查看遗漏 · 点「清空」重新开始

📱 浏览器要求

需要 Chromium 内核浏览器：Chrome / Edge / 三星 / Brave / Opera。建议安装到桌面。

关于加签：选「加签」需通过 https 打开本页（GitHub Pages 默认满足）；若设备不支持在线签名计算，请改用「自定义关键词」方式。

限流：钉钉机器人每分钟最多 20 条，本工具已按每条间隔 0.5 秒排队发送。
